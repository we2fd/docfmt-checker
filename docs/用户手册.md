# 用户手册

> 面向使用者（学生、指导老师、教务老师）的操作说明。
> 全程在浏览器里完成，无需安装任何软件（服务端已由开发者部署好）。

## 一、界面总览

打开 `http://127.0.0.1:8300`（端口以实际部署为准）后，界面分为三块：

```
┌─────────────────────────────────────────────────────────────────────┐
│  格致 · 学术文档格式智能检查与规范化助手          [检查][规则集][统计] │  ← 顶部导航
├──────────────────┬──────────────────────────────────────────────────┤
│  左侧栏           │  主工作区                                        │
│                  │                                                  │
│  · 上传论文       │  ┌ 文档概览：体检分 + 等级 + 四维度条形图 ┐      │
│  · 一键载入样例   │  │                                        │      │
│  · 文档列表       │  ├ 四维雷达图 ─────────────────────────────┤      │
│                  │  │                                        │      │
│                  │  ├ 页签：[问题清单][原文对照][修复与导出]──┤      │
│                  │  │  [规则执行明细]                        │      │
│                  │  └────────────────────────────────────────┘      │
└──────────────────┴──────────────────────────────────────────────────┘
```

顶部三个页签：

| 页签 | 用途 |
| --- | --- |
| **检查** | 主工作台：上传、体检报告、定位、修复、导出 |
| **规则集** | 查看/编辑 56 条规则；**快速调整**阈值；**上传参考模板反推规则**；可视化启停；查看 YAML 原文 |
| **统计** | 累计检查文档数、平均分、最常见问题 TOP 5 |

规则集页签内部有五个子页签：**可视化配置 / 快速调整 / 参考模板校准 / YAML 原文 / 规则集说明**，
详见第六节。

## 二、最快上手：载入演示样例

左侧栏有「**一键载入演示样例**」，随项目预置 4 份文档：

| 样例 | 体检分 | 特点 |
| --- | --- | --- |
| `01-规范样本.docx` | **100** | 完全符合规范，用于验证"不误报" |
| `02-排版问题样本.docx` | 46 | 字号/行距/页边距/空行问题密集 |
| `03-结构问题样本.docx` | 71 | 缺关键词、图表跳号、标题跳级 |
| `04-一致性与标点样本.docx` | 66 | 同段字号不一、中英标点混用 |

**点一下样例名即可**：自动上传 → 自动检查 → 报告出现在右侧。
无需先上传再点检查，这是为演示场景做的串联。

## 三、检查自己的论文

### 1. 上传

把 `.docx` 文件拖入左侧上传区，或点击选择文件。

- 支持格式：**仅 `.docx`**（Word 2007 及以上）
- 大小限制：默认 20 MB
- **同一份文件重复上传会自动识别**（按内容哈希），不会在列表里出现重复项

### 2. 常见上传失败与处理

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 「不支持的文件类型」 | 传的是旧版 `.doc` / `.wps` / `.pdf` | 用 Word 打开 → 「另存为」→ 文件类型选「Word 文档 (*.docx)」 |
| 「上传的文件是空的」 | 文件 0 字节 | 确认文件是否下载完整 |
| 「文档无法解析」 | 文件损坏，或后缀是 `.docx` 但内容不是 docx | 用 Word 打开后重新另存一次 |
| 「文件超过大小限制」 | 超过 20 MB | 图片降采样后重新保存，或联系部署者调高 `DOCFMT_MAX_UPLOAD_MB` |

> 报错框里给的都是**下一步动作**，不是"操作失败"这种无信息提示。

### 3. 看报告

检查完成后，主工作区自上而下依次是：

**① 体检分卡**

一个大号分数 + 等级（A/B/C/D/E）+ 一句话结论。
分数算法见下：

```
维度分 = 通过规则数 / (通过 + 未通过)        # "待人工确认"不参与
总分   = Σ(维度分 × 权重)                    # 排版30% 结构30% 一致性20% 内容20%
最终分 = 总分 − min(30, error 问题条数 × 4)
等级   = A≥90 / B≥80 / C≥70 / D≥60 / E<60
```

**② 四维度条形图 + 四维雷达图**

排版 / 结构 / 一致性 / 内容四个维度的得分。
若某个维度全部规则都"无法判定"，该维度会显示为**不参与计分**，
而不是记 0 分——避免无理由拉低总分。

**③ 页签区**

| 页签 | 内容 |
| --- | --- |
| **问题清单** | 每条问题：位置、实际值、规范要求、整改建议 |
| **原文对照** | 左侧显示原文段落（有问题的段高亮标红） |
| **修复与导出** | 勾选低风险修复项 → 生成新文件；导出报告 |
| **规则执行明细** | 56 条规则各自的判定结果（通过/未通过/待确认） |

## 四、问题清单怎么读

每条问题卡片包含四个要素：

```
┌─ [错误] 正文字号 ──────────────────────────────────┐
│  位置：第 12 段（正文）                             │
│  原文：随着深度学习技术的发展……                      │
│  实际值：14 磅（段落/文字直接格式）                  │
│  规范要求：12 磅                                    │
│  整改建议：选中正文 → 开始 → 字体 → 字号选「小四」    │
│  依据：《本科毕业论文撰写规范》正文格式要求           │
│                          [定位到原文] [忽略并记住]   │
└────────────────────────────────────────────────────┘
```

**重点看"实际值"后面的括号**——它告诉你这个格式是从哪来的：

| 括号里写的 | 含义 | 整改方式 |
| --- | --- | --- |
| **段落/文字直接格式** | 有人手工选中改过 | 清除直接格式，让它跟随样式 |
| **样式「正文」** | 跟着某个样式走 | 改样式定义，一改全变 |
| **文档默认值** | 谁都没设，是默认值 | 改文档默认字体设置 |
| 未能识别（需人工确认） | 解析不到该属性 | 按建议人工核对 |

> 这是本工具与"只看字号对不对"的检查方式的**本质区别**：
> 同样的"字号 14 磅"，来源不同，改法完全不同。

### 「定位到原文」

点按钮 → 自动切到「原文对照」页签，滚动到该段并高亮。
"页码缺失"这类**没有具体段落**的问题不会显示这个按钮。

### 「忽略并记住」

如果你确认某条问题**不改**（比如学校允许某种写法），点「忽略并记住」，
这条问题会从清单里隐去，并在**本浏览器**记住这个选择（换浏览器或清缓存后失效）。

## 五、修复与导出

### 为什么不做"全自动修复"

修复页签顶部有醒目提示，这也是答辩时的必讲点：

- Word 的格式是**继承**出来的，全自动改写有把论文改坏的风险；
- 因此只提供 **4 项低风险操作**，每项可单独勾选；
- 修复结果**一律生成为新文件，原文件绝不改动**。

### 四项修复操作

| 操作 | 做什么 | 风险 | 边界 |
| --- | --- | --- | --- |
| **压缩连续空行** | 2 个以上连续空段落压成 1 个 | 低 | 只删纯空段落 |
| **统一中英文标点** | 中文语句里的半角 `, . ; : ? !` 改全角 | 低 | 只处理中文占比高的段落，跳过参考文献与表格 |
| **统一正文字号** | 正文字号统一回全文"多数派" | 中 | **只改已显式设置过**且偏离多数派的段落 |
| **重排图表编号** | 图/表题注编号重排为连续序号 | 中 | 保留"3-1"式章节前缀，只改数字不动文字 |

### 操作步骤

1. 勾选想要的修复项（默认 4 项都勾上）。
2. 点「**生成规范化文件**」。
3. 下方显示「共修改 N 处」，并**逐项列出改了哪几处、原文是什么**。
4. 点「**下载修复后的文档**」保存新文件。
5. 建议把新文件**再上传检查一次**，确认分数变化。

> 修复**不会**自动帮你去补参考文献、改页边距、修标题层级——
> 这些要么涉及内容判断，要么改动范围大，交给人来做更安全。

### 导出报告

| 按钮 | 产物 | 用途 |
| --- | --- | --- |
| **导出整改清单** | `.md` 文件 | 按维度分组的纯文本清单，方便贴进笔记或提交给老师 |
| **导出 HTML 报告** | `.html` 文件 | 可直接双击打开/打印的完整报告，**样式内联，单文件即可查看** |
| **复制为 Markdown** | 复制到剪贴板 | 直接粘到微信/邮件里 |

## 六、规则集页签

### 可视化配置

56 条规则按维度列成表格，每条前面有开关，右侧显示检查器、级别、参数。
关掉某条规则，它立刻从检查中移除（判定结果标为"已停用"，不进评分分母）。

**什么时候用**：学校模板与内置默认不同，临时试算某条规则的影响。

### 快速调整

把"靠数字判定"的规则摊成一张表单，**直接改数字就能改规则**，不用写 YAML。

进来会看到 10 个分组、共 30 项可调阈值：

| 分组 | 可以改什么 |
| --- | --- |
| 纸张与分节 | 纸张宽高（A4 = 21 × 29.7 厘米） |
| 页边距 | 上 / 下 / 左 / 右页边距 |
| 论文题目 | 题目字体、题目的字号 |
| 正文 | 正文字体（多选）、正文字号、行距（倍数）、行距（固定值）、对齐方式、首行缩进 |
| 各级标题 | 一 / 二 / 三级标题的字体与字号、一级标题对齐、标题段前间距 |
| 图表题注 | 题注字号、题注对齐 |
| 摘要 / 关键词 / 参考文献 | 各自的字体与字号 |
| 内容规范 | 摘要字数区间、关键词个数、参考文献条数 |

用法：

1. 直接改数字（字号还能顺手改「容差」——容差是允许的浮动范围，
   例如 12 磅 ±0.5 表示 11.5～12.5 都算合格）；
2. 改过的卡片会**变成黄色底**，页签标题上出现「N 项待保存」；
3. 点「保存调整」，立刻对新检查生效；不想改了可以点「放弃修改」。

> 提示：这里**只动阈值**（expected / tol / min / max / allowed）。
> 检查对象（scope）、检查器（checker）、严重级别（severity）都不会被改动——
> 想改这些请用「YAML 原文」页签。

### 参考模板校准

内置的 56 条阈值是**通用口径**，不是你们学校的口径。这个页签用来把规则
换成**你们学校模板**的样子。

**准备一份"格式已经正确"的模板**（学校下发的模板文件，或导师认可的定稿），然后：

1. 点「选择参考模板（.docx）」上传；
2. 页面先给出**模板格式画像**——按角色（题目 / 各级标题 / 正文 / 摘要 / 关键词 /
   图表题注 / 参考文献）列出量到的字体、字号、行距、对齐、首行缩进，以及页面设置。
   先核对一遍，"模板本身是否规范"是这一步的前提；
3. 下面是**逐条对照表**：

   | 列 | 含义 |
   | --- | --- |
   | 当前阈值 | 规则现在要求的值 |
   | 模板实测 | 从模板里量出来的值（取**众数**，不是平均值） |
   | 占比 | 众数出现次数 / 参与统计的段落数。例如 `12/12 (100%)` 表示模板里这 12 处完全一致 |
   | 推导结果 | 建议改成什么 |

4. 每条前面有勾选框，**默认只勾选"确实需要变更"的那些**。占比低于 80% 会标黄，
   提示"这个模板自己就不统一，动手前先核对"；
5. 点「应用到规则集」→ 弹窗确认 → 写回规则集，并在规则集说明里记下"阈值来自哪份模板"；
6. 应用后页面会自动**重新推导一次**，让"已经一致"的项变成绿色的「与当前一致」。

**没有阈值可改的规则**（标题不跳级、图表编号连续、必须包含摘要、标点统一……）
会显示为灰字说明"本身没有可调的数值阈值"；
**一致性规则**（全文该属性应统一）虽然没有阈值，但会量出模板的实测值和占比，
作为你自查时的参照。

**想反悔**：点右上角「恢复内置默认」即可整体回退。

### YAML 原文

可以直接编辑规则集的 YAML 源码并保存。适合：

- 批量调整阈值（如把正文字号从 12 改成 14）；
- 增删规则；
- 把调好的规则集复制出来存档。

保存时若 YAML 语法有误，会给出**带行列号的错误提示**（例）：

```text
YAML 语法错误：mapping values are not allowed here
  in "<unicode string>", line 4, column 12:
        name: 坏: 值
               ^
```

> ⚠️ **写 YAML 的坑**：值里含"冒号 + 空格"必须加引号。
> 例如 `年份: 页码` 要写成 `"年份: 页码"`，否则会被当成嵌套映射。

### 恢复内置默认

一键把规则集复位到出厂状态。
**演示前建议先点一次**，避免忘了之前改过什么导致结果对不上。

## 八、常见问题

**Q：报告说"待人工确认"是什么意思？**
A：这条规则在**你这份文档里无法判定**（比如文档没有参考文献章节，
就判不了"著录要素是否完整"）。它不是"有问题"，也**不扣分**，
只是提醒你人工核对一下。

**Q：为什么我的规范文档也有"待人工确认"？**
A：同上，属于"无法判定"而非"不合格"。只要分数是 100、没有红色问题卡，
就说明没有误报。

**Q：修复后的文档格式会更好吗？**
A：只会更整齐，不会更差——四项操作都是保守的。
但**不会**帮你补齐缺失的内容性要素（参考文献、关键词等），这些要自己补。

**Q：这套规则是根据什么定的？**
A：是**手工写的通用本科毕业论文口径**，阈值取自"上下 2.5cm、左 3.0cm、右 2.5cm，
正文宋体小四（12 磅）、1.5 倍行距"这一常见要求——**不是**从某份官方文件抄来的，
也没有任何学校的授权。所以它只适合当"通用体检"，**校标以你们学校的文件为准**。
要用你们自己的口径，请用「快速调整」逐项改，或「参考模板校准」直接按模板反推。

**Q：参考模板推导出来的值可以直接信吗？**
A：看**占比**那一列。`12/12 (100%)` 说明模板这 12 处完全一致，可信度高；
占比低于 80% 会标黄，通常意味着模板本身就有混用（比如从别处粘贴进来的段落），
这时建议先在 Word 里把模板改干净，再重新上传。
另外系统**不会自动应用**推导结果，必须你自己勾选后点「应用到规则集」才生效。

**Q：能检查 `.pdf` 或 `.doc` 吗？**
A：目前只支持 `.docx`。`.doc` 请先另存为 `.docx`。
`.pdf` 无法提取 Word 的样式继承信息，做不了这种精度的格式检查。

**Q：数据存在哪里？会上传吗？**
A：全部存在本机（SQLite 元数据 + 本地文件），**不联网、不上传任何服务器**。

**Q：端口被占用怎么办？**
A：启动时换端口：`python -m uvicorn app.main:app --port 8301`；
或设环境变量 `DOCFMT_PORT=8301`。
